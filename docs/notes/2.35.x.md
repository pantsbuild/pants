### General

`pantsd` now reuses dependency visibility validation across runs. Validation is done for each target whose dependencies are resolved, and it depended on the set of goals executing, which is mutated during a run and so never compared equal to the next run's. Every run therefore re-ran it for every target.

Dependency visibility validation is now skipped only when `lint` is the only goal requested, where the `visibility` linter reports every violation. A run with other goals, such as `pants lint test`, now validates during `lint` as well, so a violation fails the run instead of being listed by the `visibility` linter.

#### Python

Added default module mappings for the `Cython` distribution, which provides the `Cython` and `cython` modules.

The built-in default tool lockfiles were switched from `pex` to `uv` format. This should have no
functional impact, but if you notice a bug that you think is related, please [report it](https://github.com/pantsbuild/pants/issues).

Upgraded the default `docformatter` version to 1.7.8, so that Python 3.13 and 3.14 are supported.

Upgraded the default `coverage-py` version to 7.14.3.

### Plugin API changes
