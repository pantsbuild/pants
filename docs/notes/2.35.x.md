# 2.35.x Release Series

Pants is a fast, scalable, user-friendly build system for codebases of all sizes.

Pants is an open-source project that is not owned or controlled by any one company or organization, and does incur some expenses. These expenses are managed by Pants Build, a non-profit that was established for this purpose. This non-profit's only source of revenue is [sponsorship](https://www.pantsbuild.org/sponsorship) by individuals and companies that use Pants.

We offer [formal sponsorship tiers for companies](https://www.pantsbuild.org/sponsorship), as well as individual sponsorships via [GitHub](https://github.com/sponsors/pantsbuild).

Thank you to [Klaviyo](https://www.klaviyo.com/) and Depot (https://depot.dev/) for their Platinum tier support through throughout this release.

#### Python

The built-in default tool lockfiles were switched from `pex` to `uv` format. This should have no
functional impact, but if you notice a bug that you think is related, please [report it](https://github.com/pantsbuild/pants/issues).

Upgraded the default `docformatter` version to 1.7.8, so that Python 3.13 and 3.14 are supported.

Upgraded the default `coverage-py` version to 7.14.3.

#### Shell

#### Trivy

The new `[trivy].checks` option loads custom Rego checks from the repository into every Trivy run. Pants adds the matched files to the sandbox and passes them with `--config-check`, along with the namespaces in the new `[trivy].check_namespaces` option (default `["user"]`). Previously a check file only reached the sandbox as a dependency of each linted target ([#23753](https://github.com/pantsbuild/pants/issues/23753)).

#### Javascript

Fixed a bug where installing a `pnpm` workspace package did not install the dependencies of its workspace dependencies, so that importing them failed at runtime ([#23752](https://github.com/pantsbuild/pants/issues/23752)).
