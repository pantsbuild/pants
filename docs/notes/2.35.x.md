#### Python

The built-in default tool lockfiles were switched from `pex` to `uv` format. This should have no
functional impact, but if you notice a bug that you think is related, please [report it](https://github.com/pantsbuild/pants/issues).

When using `uv` lockfiles, you can set a new `[python].create_venv_repository_from_entire_lockfile`
option. This affects how Pants builds the intermediate, internal-only venvs that pex uses as
wheel repositories. If true (the default) the entire lockfile will be materialized into the venv,
resulting in creation of fewer, larger venvs. If false, only the requirements actually needed
by the pex will be used, resulting in creation of more, smaller venvs. This may be useful if
you have a lockfile with massive requirements that are not always needed. Note that when first
setting this option to False you may need to regenerate the lockfile to ensure that it contains
enough information to create the subset venv.

`generate-lockfiles` (without `--sync`) now overwrites an existing `uv` lockfile that fails to parse, rather than failing with a `TOMLDecodeError`.

Upgraded the default `docformatter` version to 1.7.8, so that Python 3.13 and 3.14 are supported.
